# NeoPain Research Dashboard

A Streamlit-based academic demonstration of the multimodal neonatal pain-classification research project.

## Run locally

From this directory, activate your virtual environment and run:

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Expected local assets

Place the existing research evaluation CSVs in `data/`:

- `reviewer1_summary_statistics.csv`
- `pooled_auc_summary.csv`
- `all_per_subject_metrics.csv`

Place existing research figures in `assets/figures/`.

No synthetic results or individual predictions are generated by this dashboard.

## Important research distinctions

- The original UCL source dataset describes 112 neonates, 20-channel EEG and 4-second epochs.
- The project's local processing audit (308/310) is a separate processing count and should not be confused with the source cohort size.
- Current notebook configuration: 300 estimators, max depth 3, learning rate 0.03.
- The camera-ready paper configuration differs; reconciliation remains pending.
- LOSO is subject-independent evaluation within the available dataset, not external validation.
- PICS is used for ECG/HRV preprocessing validation, not external validation of the UCL classifier.
- Six PIPP-associated features are present in the current feature matrix; their provenance and possible overlap with PIPP components require investigation.
- This is a research demonstration, not a clinical diagnostic tool.
